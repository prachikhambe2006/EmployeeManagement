# Employee Management System

A simple Employee Management module developed using Git & GitHub version control practices for the TechNova Systems Pvt. Ltd. scenario.

## Features
- Add Employee (Employee ID, Name, Department, Salary)
- Display Employee Details
- Search Employee by ID
- Delete Employee Record

## Technologies Used
- HTML
- CSS
- JavaScript (localStorage)

## Branching Strategy
- **main** – stable, production-ready code
- **develop** – integration branch for features
- **feature/add-employee** – Add Employee functionality
- **feature/search-employee** – Search Employee functionality

## How to Run
Open `index.html` in any web browser.
